# Agent Skills

There are many repos out there with agent skills. Many of them are quite
advanced, covering lots of software engineering use cases with scripts, wiring
for lots of harnesses, evals and more.

These are mine. They're here for my agents to use, based around workflows
that have worked for me. You are welcome to use them if they work for you.

## Install

In Claude Code:

```
/plugin install agent-skills --marketplace sit/agent-skills
```
